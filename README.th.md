# คู่มือ EasySet (ภาษาไทย)

EasySet คือโปรแกรมสำหรับตั้งค่า Windows เครื่องใหม่ให้เป็นแบบที่ต้องการ โดยติ๊กเลือกจากหน้าต่างเดียว มีทั้งภาษาและรูปแบบวันที่เวลา นาฬิกา คีย์บอร์ด File Explorer แถบงาน (taskbar) ไอคอนบนเดสก์ท็อป และค่าอื่น ๆ ของ Windows ถ้าไม่ชอบผลที่ได้ ก็ย้อนกลับได้

โปรแกรมเป็นไฟล์ `EasySet.exe` ไฟล์เดียว ไม่ต้องติดตั้ง หน้าต่างใช้ปุ่มและช่องติ๊กมาตรฐานของ Windows จึงใช้ปุ่ม Tab กับ NVDA ได้ทุกส่วน

## ก่อนใช้งาน

- ใช้ได้กับ Windows 10 และ Windows 11
- วางโปรแกรมไว้ในโฟลเดอร์ที่เขียนไฟล์ได้ เช่น Documents, Desktop หรือแฟลชไดรฟ์ ไม่ใช่ใน Program Files เพราะโปรแกรมจะสร้างโฟลเดอร์ `EasySetBackup` ไว้ข้างตัวเองเพื่อเก็บค่าเดิมก่อนเปลี่ยน
- ตอนเปิดครั้งแรก Windows อาจเตือนว่าไม่รู้จักผู้พัฒนา ให้เลือก More info แล้วเลือก Run anyway

## หน้าต่างของโปรแกรม

เมื่อเปิดโปรแกรม โฟกัสจะอยู่ที่ช่องติ๊กช่องแรก กด Tab เพื่อไปช่องถัดไป และกด Shift+Tab เพื่อย้อนกลับ

ช่องติ๊กแบ่งเป็นกลุ่ม NVDA จะอ่านชื่อกลุ่มเมื่อโฟกัสเข้าไปในกลุ่มใหม่ ลำดับของ Tab เป็นดังนี้

1. Language and region (ภาษาและภูมิภาค)
2. Date and time (วันที่และเวลา)
3. Keyboard and cursor (คีย์บอร์ดและเคอร์เซอร์)
4. File Explorer
5. Taskbar (แถบงาน)
6. Desktop icons (ไอคอนบนเดสก์ท็อป)
7. Windows
8. Security (ความปลอดภัย)
9. ช่อง Backup, ปุ่ม และช่อง Status ท้ายหน้าต่าง

### ช่องติ๊กบอกอะไร

ทุกครั้งที่เปิดโปรแกรม ช่องติ๊กจะแสดงสถานะจริงของเครื่องตอนนั้น

- ติ๊กอยู่ = ค่านี้ตั้งไว้แล้วในเครื่อง
- ไม่ได้ติ๊ก = ค่านี้ยังไม่ได้ตั้ง

กด Spacebar เพื่อติ๊กหรือเอาติ๊กออก

การเอาติ๊กออกแล้วกด Apply ไม่ได้ปิดค่านั้น ยกเว้นช่อง Control Panel ในกลุ่ม Desktop icons ถ้าอยากกลับไปใช้ค่าเดิม ให้ใช้ปุ่ม Undo last change

## ปุ่มต่าง ๆ

| ปุ่ม | คีย์ลัด | ใช้ทำอะไร |
|---|---|---|
| Backup (ช่องติ๊ก) | Alt+B | ติ๊กไว้ = กด Apply แล้วจะสำรองค่าเดิมก่อนเปลี่ยน เพื่อให้ Undo last change คืนค่าได้ ไม่ติ๊ก = ไม่สำรอง |
| Apply | Alt+A | ตั้งค่าทุกช่องที่ติ๊กไว้แต่เครื่องยังไม่ได้ตั้ง ช่องที่ตั้งไว้แล้วจะข้ามไป |
| Undo last change | Alt+U | ย้อนการเปลี่ยนแปลงครั้งล่าสุด ปุ่มนี้มีให้เห็นเฉพาะเมื่อมีการเปลี่ยนแปลงที่ย้อนได้ |
| Status | Alt+S | ช่องข้อความที่บอกผลการทำงาน กด Alt+S เพื่อย้ายโฟกัสไปอ่าน |
| Exit | Alt+X หรือ Esc | ปิดโปรแกรม |

### Backup

Backup เป็นช่องติ๊ก อยู่เหนือปุ่ม Apply และจะติ๊กไว้ให้ทุกครั้งที่เปิดโปรแกรม

- ติ๊กไว้: ก่อนเปลี่ยนค่า Apply จะสำรองค่าเดิมของส่วนที่กำลังจะเปลี่ยนเป็นไฟล์เดียวนามสกุล .oabi ในโฟลเดอร์ `EasySetBackup` ชื่อไฟล์เป็นวันและเวลาที่สำรอง เช่น `20261117_144900.oabi` ถ้าสำรองไม่สำเร็จ โปรแกรมจะไม่เปลี่ยนอะไรเลย และหลังจากนั้นจะมีปุ่ม Undo last change ให้ย้อนกลับได้
- ไม่ติ๊ก: Apply จะเปลี่ยนค่าเลยโดยไม่สำรอง การเปลี่ยนแปลงครั้งนั้นจึงย้อนด้วย Undo last change ไม่ได้

กด Spacebar เพื่อติ๊กหรือเอาติ๊กออก เหมือนช่องติ๊กอื่น

### Apply

1. ติ๊กช่องที่ต้องการ
2. กด Apply (Alt+A)
3. ระหว่างทำงาน ช่อง Status จะขึ้นว่า `Applying the selected settings. Please wait.` ช่วงนี้ปุ่มต่าง ๆ จะกดไม่ได้ และปิดโปรแกรมไม่ได้จนกว่าจะเสร็จ
4. ถ้าทุกอย่างสำเร็จ ช่อง Status จะขึ้นว่า `Done.` โดยไม่มีหน้าต่างข้อความเด้งขึ้นมา

หน้าต่างข้อความจะเด้งขึ้นมาเฉพาะตอนที่ต้องบอกอะไรเพิ่ม เช่น

- มีบางค่าที่ตั้งไม่สำเร็จ ข้อความจะบอกชื่อค่านั้นและสาเหตุ
- ต้องรีสตาร์ทเครื่อง หรือต้องเปิดโปรแกรมที่ค้างอยู่ใหม่ ค่าจึงจะมีผลเต็มที่

ถ้าไม่มีช่องไหนต้องเปลี่ยน ช่อง Status จะขึ้นว่า `Nothing to change.`

บางค่าเปลี่ยนค่าของทั้งเครื่อง ถ้า Windows ถามยืนยัน (UAC) ให้ตอบ Yes โปรแกรมจะเปิดตัวเองใหม่แล้วตั้งค่าที่เลือกไว้ต่อให้ทันทีโดยไม่ต้องติ๊กใหม่ ถ้าตอบ No จะไม่มีอะไรเปลี่ยน ถ้าปิดการถาม UAC ไว้แล้ว จะไม่มีหน้าต่างถามขึ้นมา

### Undo last change

Undo ย้อนได้เฉพาะการเปลี่ยนแปลงที่กด Apply ตอนช่อง Backup ติ๊กอยู่

1. กด Undo last change (Alt+U)
2. โปรแกรมจะถามว่าจะคืนค่าที่เก็บไว้หรือไม่ ปุ่มที่โฟกัสอยู่ตอนแรกคือ No เพื่อกันกด Enter พลาด ถ้าต้องการย้อนจริงให้เลือก Yes
3. เมื่อเสร็จ จะมีข้อความบอกว่าคืนค่าเดิมแล้ว ถ้าย้อน Language for non-Unicode programs ด้วย ข้อความจะบอกให้รีสตาร์ทเครื่อง

กด Undo ซ้ำได้ เพื่อย้อนการเปลี่ยนแปลงครั้งก่อนหน้าไปทีละครั้ง เมื่อไม่มีอะไรให้ย้อนแล้ว ปุ่มนี้จะหายไป

ข้อควรรู้: Undo จะคืนค่าทั้งส่วนที่เก็บไว้ ถ้าหลังจาก Apply คุณไปเปลี่ยนค่าอื่นในส่วนเดียวกันเอง ค่านั้นจะถูกย้อนกลับไปด้วย

## ช่องติ๊กทั้งหมด

### Language and region (ภาษาและภูมิภาค)

| ช่อง | ใช้ทำอะไร |
|---|---|
| Regional format: English (United States) | รูปแบบวันที่ เวลา ตัวเลข และเงินแบบอเมริกัน: วันที่เป็น 11/16/2026, เวลาแบบ 12 ชั่วโมงเช่น 2:49 PM, เงินดอลลาร์ ($), ปี ค.ศ., สัปดาห์เริ่มวันอาทิตย์ |
| Regional format: Thai (Thailand) | รูปแบบไทย: วันที่เป็น 16/11/2569, เวลาแบบ 24 ชั่วโมงเช่น 14:49, เงินบาท (฿), ปี พ.ศ., สัปดาห์เริ่มวันจันทร์, ชื่อวันและเดือนเป็นภาษาไทย |
| Country or region: Thailand | ตั้งประเทศเป็นไทย Windows และแอปใช้ค่านี้เลือกเนื้อหาของประเทศ และช่อง Set time zone automatically ใช้ค่านี้เลือกเขตเวลา |
| Languages: English and Thai | ตั้งรายการภาษาเป็นอังกฤษ (สหรัฐอเมริกา) และไทย โดยให้อังกฤษอยู่ก่อน เมนูของ Windows จึงยังเป็นภาษาอังกฤษ |
| Language for non-Unicode programs: Thai (Thailand) | ให้โปรแกรมเก่าที่ไม่รองรับ Unicode แสดงภาษาไทยถูกต้อง ไม่เป็นตัวอักษรแปลก ๆ ต้องรีสตาร์ทเครื่อง มีผลกับทุกคนที่ใช้เครื่องนี้ |
| Keyboard layouts and language switch key (Grave Accent) | ตั้งแป้นพิมพ์อังกฤษ (US) และไทย (เกษมณี) และใช้ปุ่ม Grave Accent (ปุ่ม ~ ใต้ Esc) สลับภาษา ถ้ารายการภาษายังไม่มีภาษาไทย โปรแกรมจะเพิ่มให้ด้วย |

Regional format เลือกได้ทีละแบบ: ติ๊ก Thai แล้วช่อง English จะหลุดติ๊กเอง และกลับกันก็เช่นกัน ทั้งสองแบบใช้ค่ามาตรฐานของภาษานั้นตามที่ Windows กำหนด

### Date and time (วันที่และเวลา)

| ช่อง | ใช้ทำอะไร |
|---|---|
| Set time zone automatically | ตั้งเขตเวลาตามประเทศที่ตั้งไว้ใน Country or region ก่อน แล้วให้ Windows ปรับเขตเวลาตามตำแหน่งของเครื่องเองหลังจากนั้น และจะเปิดบริการตำแหน่ง (location) ของ Windows ด้วย |
| Set time automatically | ให้นาฬิกาตั้งเวลาเองให้ตรงผ่านอินเทอร์เน็ต |

- โปรแกรมรู้เขตเวลาของไทย ถ้าประเทศที่ตั้งไว้เป็นประเทศอื่น โปรแกรมจะไม่เปลี่ยนเขตเวลา และจะบอกให้ทราบ
- ติ๊ก Country or region: Thailand พร้อมกับช่องนี้ได้ ถึงช่องนี้จะติ๊กอยู่แล้ว โปรแกรมก็จะตั้งเขตเวลาของไทยให้ใหม่เมื่อเปลี่ยนประเทศ
- ถ้าเครื่องไม่ได้ต่ออินเทอร์เน็ต เขตเวลาจะยังตั้งตามประเทศได้ ส่วนนาฬิกาจะตั้งเวลาให้ตรงเองเมื่อออนไลน์ครั้งถัดไป

### Keyboard and cursor (คีย์บอร์ดและเคอร์เซอร์)

| ช่อง | ใช้ทำอะไร |
|---|---|
| Keyboard repeat delay: shortest | เมื่อกดปุ่มค้างไว้ ปุ่มจะเริ่มพิมพ์ซ้ำเร็วที่สุด |
| Cursor blink rate: fastest | เคอร์เซอร์ข้อความกะพริบเร็วที่สุด |
| Keyboard shortcut for Sticky keys: off | กด Shift 5 ครั้งแล้วจะไม่เปิด Sticky keys อีก |
| Keyboard shortcut for Filter keys: off | กด Shift ขวาค้าง 8 วินาทีแล้วจะไม่เปิด Filter keys อีก |

### File Explorer

| ช่อง | ใช้ทำอะไร |
|---|---|
| Show file name extensions | แสดงนามสกุลไฟล์ เช่น `.txt`, `.exe`, `.mp3` ต่อท้ายชื่อไฟล์ |
| Group by: None | ไม่จัดกลุ่มไฟล์ในโฟลเดอร์ เช่น Downloads จะไม่แบ่งเป็น Today, Yesterday, Earlier this week |
| Sort by: Name, ascending | เรียงไฟล์ตามชื่อจาก A ถึง Z และเรียงไอคอนบนเดสก์ท็อปตามชื่อด้วย |
| View: Details | แสดงไฟล์เป็นรายการพร้อมคอลัมน์ ชื่อ วันที่ ประเภท และขนาด ด้วยไอคอนเล็ก |

สามช่องหลัง (Group by, Sort by และ View) มีผลกับทุกโฟลเดอร์ รวมถึง Downloads, This PC และหน้าต่าง Open/Save ของโปรแกรมต่าง ๆ

ขณะตั้งสามค่านี้ โปรแกรมต้องปิดแล้วเปิด File Explorer ใหม่:

- taskbar จะหายไปครู่หนึ่งแล้วกลับมา
- หน้าต่างโฟลเดอร์ที่เปิดอยู่จะปิดแล้วจะเปิดกลับมาใหม่

หลังจากนั้นยังเปลี่ยนมุมมองของโฟลเดอร์ไหนก็ได้ตามปกติใน File Explorer ถ้าภายหลังไปเปลี่ยนมุมมองของ This PC เอง ช่องเหล่านี้จะไม่ติ๊ก เพราะเครื่องไม่ได้ตั้งตามนี้ทุกที่แล้ว

### Taskbar (แถบงาน)

| ช่อง | ทำอะไร |
|---|---|
| Search: Hide | ซ่อนช่องค้นหาหรือปุ่มค้นหาบน taskbar ยังค้นหาได้โดยกดปุ่ม Windows แล้วพิมพ์ |
| Task view: Off | ซ่อนปุ่ม Task view บน taskbar ยังเปิด Task view ได้ด้วย Windows+Tab |
| Widgets: Off | ปิด Widgets (ข่าว อากาศ ฯลฯ) และซ่อนปุ่มบน taskbar ใช้กับทุกบัญชีในเครื่อง |
| Unpin all apps | เอาแอปที่ pin ไว้บน taskbar ออกทุกอัน เช่น Edge, File Explorer และ Microsoft Store แอปที่กำลังเปิดอยู่ยังแสดงบน taskbar ตามปกติจนกว่าจะปิด |

Search และ Task view มีผลทันที ส่วน Widgets และ Unpin all apps โปรแกรมจะปิดแล้วเปิด File Explorer ใหม่ให้เอง taskbar จะหายไปครู่หนึ่งแล้วกลับมาโดยไม่มีแอปที่ pin ไว้ ถ้าช่อง Backup ติ๊กอยู่ กด Undo last change แล้วแอปจะกลับมา pin เหมือนเดิม

### Desktop icons (ไอคอนบนเดสก์ท็อป)

| ช่อง | ใช้ทำอะไร |
|---|---|
| Computer | แสดงไอคอน This PC บนเดสก์ท็อป |
| User's Files | แสดงไอคอนโฟลเดอร์ส่วนตัวของผู้ใช้บนเดสก์ท็อป |
| Network | แสดงไอคอน Network บนเดสก์ท็อป |
| Recycle Bin | แสดงไอคอนถังขยะบนเดสก์ท็อป |
| Control Panel | แสดงไอคอน Control Panel บนเดสก์ท็อป |
| Allow themes to change desktop icons | ให้ธีมของ Windows เปลี่ยนรูปไอคอนเหล่านี้ได้ |

ช่อง Control Panel ทำงานเหมือนหน้าต่าง Desktop icon settings ของ Windows: ติ๊ก = แสดงไอคอน, เอาติ๊กออกแล้วกด Apply = ซ่อนไอคอน

### Windows

| ช่อง | ใช้ทำอะไร |
|---|---|
| Classic right-click menu | ใช้เมนูคลิกขวาแบบคลาสสิกที่แสดงครบทุกคำสั่ง (Windows 11 ปกติจะแสดงเมนูย่อก่อน แล้วต้องเลือก Show more options) โปรแกรมจะปิดแล้วเปิด File Explorer ใหม่ให้เองเพื่อให้เมนูใหม่มีผลทันที |
| Recycle Bin: display delete confirmation dialog | ให้ถามยืนยันทุกครั้งก่อนย้ายไฟล์ไปถังขยะ |
| Clear Run history | ล้างรายการคำสั่งที่เคยพิมพ์ในกล่อง Run (Windows+R) ช่องนี้จะติ๊กอยู่เมื่อรายการว่าง |
| Old Notepad | ให้ไฟล์ข้อความ (.txt) เปิดด้วย Notepad แบบคลาสสิก แทน Notepad ตัวใหม่ |

### Security (ความปลอดภัย)

| ช่อง | ใช้ทำอะไร |
|---|---|
| Do not ask for UAC confirmation (less secure) | โปรแกรมที่สั่งให้รันด้วยสิทธิ์ผู้ดูแลระบบจะได้สิทธิ์เต็มทันที โดยไม่มีหน้าต่างถามยืนยัน |

คำเตือน: ค่านี้ทำให้เครื่องปลอดภัยน้อยลง เพราะโปรแกรมใดก็ตามที่รันด้วยสิทธิ์ผู้ดูแลระบบจะเปลี่ยนค่าได้ทั้งเครื่องโดยไม่มีการถาม เลือกเฉพาะเมื่อเข้าใจผลที่จะตามมา

## เมื่อไหร่ต้อง sign out หรือรีสตาร์ท

ค่าส่วนใหญ่มีผลทันทีหลังกด Apply ไม่ต้อง sign out หรือรีสตาร์ท

- มีผลทันที: ไอคอนบนเดสก์ท็อป, แป้นพิมพ์และปุ่มสลับภาษา, รายการภาษา, ประเทศ, เขตเวลาและนาฬิกา, ค่าคีย์บอร์ดและเคอร์เซอร์, Sticky keys และ Filter keys, ถังขยะ, Old Notepad และค่าของ File Explorer
- File Explorer ปิดแล้วเปิดใหม่ให้เอง: Classic right-click menu, Widgets, Unpin all apps และสามค่าของมุมมองโฟลเดอร์ (taskbar จะหายไปครู่หนึ่งแล้วกลับมา)
- ปิดโปรแกรมแล้วเปิดใหม่ หรือ sign out: Regional format โปรแกรมที่เปิดค้างอยู่จะยังใช้รูปแบบเดิมจนกว่าจะเปิดใหม่ โปรแกรมเปิดใหม่จะใช้รูปแบบใหม่ทันที
- รีสตาร์ทเครื่อง: เฉพาะ Language for non-Unicode programs
- โปรแกรมจะบอกในหน้าต่างข้อความหลัง Apply ว่าต้องทำอะไร ถ้าไม่มีข้อความขึ้นมา แปลว่าไม่ต้องทำอะไรเพิ่ม

## การอัปเดต

ทุกครั้งที่เปิดโปรแกรม EasySet จะตรวจว่ามีรุ่นใหม่หรือไม่ โดยไม่ส่งข้อมูลอื่นออกไป ถ้าไม่ได้ต่ออินเทอร์เน็ต หรือไม่มีรุ่นใหม่ โปรแกรมจะไม่บอกอะไร

ถ้ามีรุ่นใหม่ จะมีหน้าต่างถามก่อน ปุ่มที่โฟกัสอยู่ตอนแรกคือ Yes

- เลือก Yes: โปรแกรมจะดาวน์โหลดรุ่นใหม่ ตรวจว่าไฟล์มาครบไม่เสีย แล้วเปลี่ยนตัวเองเป็นรุ่นใหม่และเปิดขึ้นมาใหม่เอง
- เลือก No: ใช้รุ่นเดิมต่อไป ครั้งหน้าที่เปิดโปรแกรมจะถามอีก

## เรื่องอื่นที่ควรรู้

- ถ้า Windows ขอรหัสผ่านของบัญชีผู้ดูแลระบบอีกบัญชีหนึ่ง ตอนถามสิทธิ์ ค่าภาษา แป้นพิมพ์ เดสก์ท็อป เมนูคลิกขวา และ File Explorer จะไปตั้งที่บัญชีนั้น ไม่ใช่บัญชีของคุณ
- เครื่องที่องค์กรดูแล (เช่น เครื่องของบริษัทหรือโรงเรียน) อาจถูกตั้งค่าบางอย่างกลับคืนโดยอัตโนมัติ
- โฟลเดอร์ `EasySetBackup` ข้างโปรแกรมเก็บไฟล์สำรอง .oabi ไว้สำหรับ Undo ถ้าลบโฟลเดอร์หรือไฟล์ .oabi จะย้อนกลับไม่ได้
- ไฟล์ .oabi ถูกเข้ารหัสไว้ เปิดได้ด้วย EasySet เท่านั้น โปรแกรมแตกไฟล์อย่าง 7-Zip เปิดไม่ได้
- อย่าเปลี่ยนชื่อหรือย้ายไฟล์ .oabi เพราะ Undo จะหาไม่เจอ ไฟล์ที่ Undo ไปแล้วจะมีคำว่า _undone ต่อท้ายชื่อ
